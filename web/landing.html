Features

一站式管理微信会话

从扫码连接到实时聊天，Zyn iLink ChatBox 提供完整的 Web 聊天界面、WebDAV 云存储、多会话管理和消息历史导出。

Web 实时聊天

浏览器直接收发消息，支持文字、图片、视频、文件

WebDAV 云存储

媒体文件存到 WebDAV，节省本机磁盘空间

多会话管理

同时管理多个会话，设置备注名，快速切换

消息历史

完整消息记录，支持导出聊天记录为 HTML

Security

本地存储
